# Knowledgebase Index

This repository holds derived, searchable learning notes from independent pipelines. Original source evidence stays in each pipeline's protected archive.

## Collections

- [Learning Inbox](learning-inbox/INDEX.md) — saved video and webpage knowledge cards.
- [Muse Instagram Reels](muse-instagram/INDEX.md) — distilled Instagram Reel knowledge cards.

Each collection owns its own index and cards. Automation must modify only its assigned collection.
