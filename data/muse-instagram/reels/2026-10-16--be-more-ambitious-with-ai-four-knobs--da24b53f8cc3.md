## Derived summary
Chase AI summarizes a Felix Rieseberg tutorial, "How to be more ambitious: A tutorial for humans with models." Rieseberg's core idea is that most people underuse capable models by assigning them small, literal tasks. He frames ambition as four adjustable knobs. Speed means getting the same work done faster. Altitude means thinking more abstractly about outcomes rather than tasks. Depth means going deeper into underlying data and the real problem. Range means drawing on multiple fields and perspectives. The reel then shares a practical prompt from the tutorial that you append to any existing prompt: it asks the model to behave like a top professional in the relevant field, reference raw source material, name the methods and tools it will use, state how the result will be validated, and rewrite the original prompt to be more ambitious. The reel's point is aimed at frequent AI users: the models are strong enough to handle much bigger asks, so the limiting factor is how ambitious the prompt is. The comment section is mostly positive about the concrete prompt, with some pushback that the approach drives token usage and needs direction.

## Practical takeaways
- When a prompt returns something shallow, do not just re-run it. Append a meta-prompt that asks the model to raise the ambition level first.
- Use the four knobs (Speed, Altitude, Depth, Range) as a checklist before sending important prompts: which knob could you turn up?
- In the meta-prompt, require the model to name its sources, methods, and validation criteria. This keeps ambition grounded instead of speculative.
